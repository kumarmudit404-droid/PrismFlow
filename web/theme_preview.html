Theme variants — phase (f) step 1

Two candidates. Neither is applied: assets/css/tokens.css is still the live theme. Every number below comes from python web/check_palette.py assets/css/tokens-a-light.css assets/css/tokens-b-ember.css.

The five angle colours are not five oranges. Orange is UI chrome only — background, surface, nav, buttons, links, focus. The angles stay categorical, and each variant was searched rather than picked: hue held within its own family, chroma floored so a category never reads as tinted grey, at least 16–18 CIEDE2000 away from the orange accent so a data colour cannot be mistaken for a button, a monotonic luminance staircase so they survive greyscale, and the worst CIEDE2000 separation maximised across normal vision and simulated deuteranopia, protanopia and tritanopia.
