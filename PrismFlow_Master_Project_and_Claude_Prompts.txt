PRISMFLOW - MASTER PROJECT CREATION GUIDE

A complete B.Tech 2nd-year friendly project roadmap, architecture, pipeline, file-generation plan, research experiments, and Claude prompts.

CORE IDEA
PrismFlow is a Multi-View Learning system. It receives multiple views of the same sample, extracts information from each view, checks how independent those views really are, estimates an effective number of independent views (ENIV), discounts duplicated or suspicious evidence, fuses the remaining evidence, and outputs a prediction together with confidence and diagnostics.

CENTRAL RESEARCH QUESTION
More agreeing views do not automatically mean more independent information. PrismFlow investigates whether a system can recognize redundant or coordinated agreement and avoid becoming overconfident because several views repeat the same information or are deliberately manipulated together.

ONE-SENTENCE THESIS
Agreement between views should contribute evidence according to how independent the views really are, not merely according to how many views agree.

IMPORTANT RESEARCH DISCIPLINE
Do not build everything at once. Build one hypothesis and one experiment at a time. Most neural components are standard. The research contribution is mainly in the measurement, dependence estimation, ENIV, attack model, calibration, and evaluation protocol.

============================================================
2. COMPONENTS - IN EASY LANGUAGE
============================================================

1) Dataset / Input Manager
Receives all views belonging to one sample and keeps them aligned.

2) Preprocessing
Cleans, normalizes, resizes, masks missing views, and simulates controlled noise/corruption.

3) View Encoders
Each view is converted into a feature vector. Use view-specific encoders; do not force all views through the same weights by default.

4) Shared / Private Representation
Separate information common to multiple views from information unique to one view.

5) Evidential Head
Produces evidence, belief/probabilities, and uncertainty for each view.

6) Dependence Engine
Measures whether two views contain strongly related or repeated information.

7) ENIV
Estimates how many independent views you effectively have. Six highly redundant views may behave more like two or three independent sources.

8) Evidence Discount
Reduces the influence of redundant/low-independence evidence instead of letting repeated agreement create fake confidence.

9) Fusion
Combines the adjusted evidence from all views.

10) Classifier
Produces the final prediction.

11) Chorus Attack Simulator
In a controlled research experiment, several views are manipulated toward the same wrong class to test whether ordinary fusion becomes overconfident.

12) Calibration / Evaluation
Checks not only whether predictions are correct, but whether confidence is honest.

13) GUI
Desktop interface for the final demo.

14) EXE Packaging
Packages the application so the user can launch PrismFlow.exe directly on Windows.

============================================================
6. RESEARCH HYPOTHESES
============================================================

H1: Duplicating a view can artificially increase confidence in naive fusion.
H2: Multiple coordinated wrong views can cause ordinary fusion to become overconfident.
H3: Dependence-aware ENIV can identify redundant evidence.
H4: Dependence discounting can reduce confidence inflation.
H5: PrismFlow can maintain better calibration under missing/noisy/collusive-view conditions.
H6: Per-sample ENIV can detect situations where views become dependent only for particular inputs.

Every hypothesis must be tested with real experiment results. Never invent numbers.

============================================================
10. CORE PRINCIPLE TO REMEMBER
============================================================

PrismFlow is not valuable because it contains the largest number of fancy AI techniques.

It is valuable if it can demonstrate, with controlled experiments, that:

- agreement can come from redundant information;
- coordinated agreement can fool ordinary fusion;
- effective independence can be estimated;
- confidence can be discounted when apparent agreement is not independent;
- calibration becomes more trustworthy under difficult multi-view conditions.
