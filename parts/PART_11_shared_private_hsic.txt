WHY HSIC RATHER THAN AN ORTHOGONALITY PENALTY
  A simple orthogonality penalty ||h_shared^T h_private||_F^2 enforces only
  LINEAR independence. Two representations can be perfectly decorrelated and
  still be deterministic functions of one another. HSIC - the Hilbert-Schmidt
  Independence Criterion - is a kernel measure that is zero if and only if the
  variables are statistically independent, for characteristic kernels. It is
  differentiable and estimable per batch in O(B^2). Implement both; default HSIC.

IMPLEMENT
  - Shared and private branches per view from the encoder features.
  - Biased HSIC estimator with an RBF kernel, median heuristic for bandwidth.
  - Disentanglement loss added to the total objective with weight lambda_2.
  - Config: shared_dim, private_dim, kernel, lambda_2, enabled flag.

NUMERICAL NOTES TO HANDLE
  - HSIC requires batch size >= 64 to be stable; assert and warn below that.
  - Centre the kernel matrices correctly (H K H with H = I - 1/n).
  - Guard against zero-variance features producing NaN bandwidth.
